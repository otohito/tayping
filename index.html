スモウルビー・タイピング対戦 / 変更は2か所
読み込み入力の練習接続対戦を始める得点を読む終了を送る受け取る仕組み対戦困ったら見本

START / 得点と終了の合図

タイピングで、つながろう。

正解すると、自分の得点が増える。
その得点が相手にも届く。5点で「終了」を伝える。

最初に、スターターを読み込む

タイピング対戦 A用・スターター ↓タイピング対戦 B用・スターター ↓
  1. 2人でA・Bを決め、自分のスターターを保存する。
  2. スモウルビーを開く ↗。
  3. 左上の ファイル → コンピューターから読み込む。
  4. タイピング対戦_A_スターター.sb3 または タイピング対戦_B_スターター.sb3 を選ぶ。

入力・正解判定・得点は用意済み。追加するのは ①相手の得点を読む、②終了を送る の2か所です。

TRY / 入力の練習

入力して、得点が増える。

  1. 次の「接続」に進み、下の「対戦を始める」の手順でスタートする。
  2. 下の入力欄をクリックし、キーボードを 半角英数 にする。
  3. 画面に表示された英単語を入力し、Enter を押す。
  4. 正解なら得点が1増えて次の単語へ。間違えたら同じ単語がもう一度出る。
画面のお題 cat↓ 下の入力欄にcat Enter ↵↓自分の得点 0 → 1

問題は順番に cat → dog → apple → book → happy。リスト「問題」に用意されています。

✓ スターターでも、準備OKとスタートの操作で入力の練習ができます。まだ相手の得点は0のまま、5点になっても終了の合図は送りません。

CONNECT / メッシュ接続

Aがホスト、Bが参加。

  1. 読み込み後のメッシュの画面を使う。出なければ左下の拡張機能から メッシュ。追加済みなら接続ボタン。
  2. ペア専用の ドメイン を2人とも同じにする。
  3. Aは メッシュのホストになる（グループの作成）。
  4. Bは メッシュに参加する（グループに参加） からAのグループを選ぶ。

1つのグループにはAとBを1つずつ。別のペアや、余分に開いたテスト作品を入れません。

START BUTTON / 対戦を始める

準備OKがそろったら、Aがスタート。

  1. A・Bとも緑の旗を押し、Aの画面で A_準備 と 相手の準備 が両方0になったことを確認する。
  2. A・Bがそれぞれ画面の 準備OK をクリックする。0は準備前、1は準備OK。
  3. Aの画面で両方が1になったら、Aが スタート をクリックする。
  4. 「スタート」を受け取った側から出題が始まる。再戦も両方の旗から。

準備は変数で共有し、始める合図はメッセージで送ります。下のブロックは準備済みです。

Aの「スタート」ボタン

両方が1になる前に押した場合、ボタンは残ります。1がそろってからもう一度押します。

STEP 1 / 得点を読む

相手の変数を、センサーで読む。

  1. 右下のスプライト一覧で 相手の得点 をクリック。
  2. 「ずっと」の中の 相手の得点を0にする を探す。
  3. 左側の メッシュ をクリック。
  4. （　）センサーの値 を作業スペースへ運ぶ。
  5. ▼から、Aの人は B_得点、Bの人は A_得点 を選ぶ。
  6. そのブロックを、オレンジ色のブロックの 0の入力欄 に入れる。

赤枠が今回の変更箇所です。自分側の図を開いて確認します。

A側の「相手の得点」
B側の「相手の得点」
Aの変数 A_得点＝1→ メッシュで届く →Bのセンサーで1を読む

センサーは相手の数値を読む部品です。読んだ数値を、この画面の「相手の得点」に入れて表示します。タイピングの答えそのものは送りません。

✓ Aが1問正解→Bの「相手の得点」が1になる。BからAへも確かめよう。開始時は表示を0に戻し、2秒待ってから受信します。再戦は両方で旗を押してください。

STEP 2 / 終了を送る

「5点まで繰り返す」の外へ。

  1. 右下の タイピング をクリック。
  2. 作業スペースに用意した、黄色の 終了 を送る を探す。
  3. 「スタートを受け取ったとき」から始まるプログラムへ運ぶ。
  4. オレンジ色の 〈自分の得点 = 5〉まで繰り返す の 外側・下 につなぐ。大きな「もし」の中に入れたままにします。
繰り返しの中には入れません。

中だと、まだ5点になっていない途中で終了してしまいます。5点まで繰り返した後に、1回だけ送ります。

赤枠が今回の変更箇所です。自分側の図を開いて確認します。

A側の「タイピング」
B側の「タイピング」

「終了」は準備済みです。▼から選ぶ場合も 終了 を選びます。「送って待つ」ではなく 送る を使います。

READ / 用意済みの処理

「終了」を受け取ると、入力を止める。

このプログラムは、A・Bの両方に用意済みです。追加しなくて大丈夫です。

赤枠が今回の変更箇所です。自分側の図を開いて確認します。

A側の「タイピング」
B側の「タイピング」

スプライトの他のスクリプトを止めるで、この「タイピング」の問題出題を止めます。別のスプライトで動いている「相手の得点を読む」処理は続くので、終了後に届いた得点も表示に反映されます。

「終了」は自分の作品にも相手の作品にも届きます。先に5点になった側が合図を出すと、両方の問題出題が止まります。

「緑の旗が押されたとき」「終了を受け取ったとき」は帽子形です。上には別のブロックをつなげません。

PLAY / 2人で試す

得点が届く、合図で止まる。

  1. 2か所の変更とメッシュ接続を両側で確認。
  2. 上の「対戦を始める」の手順で、準備OKとスタートを押す。
  3. 表示された英単語を入力してEnter。
  4. 相手の得点が増える様子を確認する。
  5. どちらかが5点になると「終了」を送り、問題出題が止まる。
  6. お互いの得点を見比べる。再戦は両方の緑の旗。
まず、やり取りできたことを確かめよう。

通信に待ち時間があるため、相手の終了が届く前にこちらも5点になることがあります。厳密な先着判定はしていません。同じ得点なら引き分けとして楽しめます。

半角で入力：cat、5、0.1。全角の「ｃａｔ」「５」「０．１」は使いません。問題は小文字の英単語です。変数名は▼から用意された名前を選びます。

✓ ①正解で1点 ②相手の画面に得点が届く ③5点で終了を送る ④両方の問題出題が止まる

HELP / 2か所を見直す

うまく動かないとき。

症状確認するところ
入力できない画面の下の入力欄をクリックし、半角英数で入力する。
同じ問題が続く表示された単語と答えが同じ？ 全角や余分な空白が入っていない？
相手の得点が0のままメッシュ接続とSTEP 1のセンサー名。AはB_得点、BはA_得点。
1問で終わってしまう「終了を送る」が、繰り返しの内側に入っていない？
5点になっても相手が止まらないSTEP 2の送るブロックはつながっている？ 両側ともメッセージ名は「終了」？

接続し直したら両方の旗を押し、最初に1問だけ正解して、相手に得点が届くか確かめます。

REFERENCE / 完成見本

まず完成。それから工夫。

タイピング対戦 A用・完成見本 ↓タイピング対戦 B用・完成見本 ↓

スターターとの差は、センサーを1個入れることと、用意された「終了を送る」をつなぐことの2点だけです。

早くできたら、リスト「問題」の単語を変えよう。はじめは5個のまま、同じリストをペアの両側へ入れると、同じ問題で対戦できます。
